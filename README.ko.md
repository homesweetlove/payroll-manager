# 조교급여대장 — Payroll Manager

**출퇴근 기록을 정리하고, 급여 계산 결과를 확인하고, 명세서까지 내보내는 웹앱.**

학원 조교·강사의 근태 자료를 바탕으로 급여를 정산하는 과정에서 반복 입력을 줄이기 위해 만든 프로젝트입니다. 직원 정보를 등록하고, 출퇴근 엑셀을 불러오고, 주휴수당·각종 가산수당·공제 항목을 확인한 후 급여대장과 임금명세서 파일을 생성할 수 있습니다.

현재는 데이터를 서버로 보내는 방식이 아니라 **사용 중인 브라우저의 `localStorage`에 보관**하고 JSON 파일로 백업·복구하는 구조입니다. 법적 정확성이 인증된 급여 계산 서비스는 아닙니다.

## 주요 기능

| 영역 | 지원 내용 |
| --- | --- |
| 직원 관리 | 이름, 직급, 시급, 기본 근무표, 급여일, 세금 방식, 고정 수당, 퇴직 관련 정보 |
| 근태 가져오기 | `.xlsx`, `.xls`, `.csv` 파일을 읽고 등록된 직원 이름과 출퇴근 기록 연결 |
| 근태 확인 | 휴게, 결근, 유급휴가, 공휴일·야간근로, 주차별 주휴수당 지급 여부 조정 |
| 급여 계산 | 기본급, 주휴수당, 연장·야간·공휴 가산, 유급연차, 기타 수당, 세금·공제, 실지급액 |
| 임금명세서 | 직원별 명세서 확인, PDF 저장, 여러 직원 명세서 ZIP 일괄 저장 |
| 파일 내보내기 | 서식 있는 `.xlsx` 급여대장, 감사용 `.csv`, 리포트·백업 `.json` |
| 대시보드 | 과거 정산 결과 조회, 감사 내역 및 비교, 기초 통계 |

공제 방식으로 **프리랜서 3.3%**, **4대보험 관련 기본 계산**, **사용자 지정 세율**을 선택할 수 있습니다. 코드에 정해진 기본 요율이 모든 고용 형태와 최신 제도에 맞는다는 뜻은 아닙니다.

## 로컬 실행

**필요 환경:** Vite 6과 호환되는 Node.js 및 npm (Node.js 20 이상 권장).

```bash
git clone https://github.com/homesweetlove/payroll-manager.git
cd payroll-manager
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 열면 됩니다.

```bash
npm run lint     # TypeScript 타입 검사
npm run build    # 배포용 빌드
npm run preview  # 빌드 결과 미리보기
```

현재 기능에는 별도 외부 API 키나 데이터베이스가 필요하지 않습니다. [`.env.example`](./.env.example) 참고.

## 사용 순서

1. **조교 관리**에서 직원명, 시급, 기본 근무 시간과 공제 방식을 입력합니다.
2. **급여 정산**에서 학원명을 정하고 출퇴근 엑셀/CSV를 업로드합니다.
3. 불러온 기록을 확인한 뒤 휴게·유급휴가·공휴근무·주휴수당 지급 조건을 조절합니다.
4. 직원별 기본급·가산수당·공제 및 최종 지급액을 검토합니다.
5. 엑셀 급여대장, 임금명세서 PDF, 결과 패키지 JSON을 필요한 형식으로 저장합니다.
6. 대시보드에서 기존 급여 이력을 검토하고 **전체 JSON 백업**을 주기적으로 내려받습니다.

### 출퇴근 파일 형식

파일의 **첫 번째 시트**, 첫 행 다음부터 다음 열을 읽습니다.

| 열 | 사용되는 데이터 |
| --- | --- |
| A | 출퇴근일 (엑셀 날짜 또는 날짜 텍스트) |
| B | 직원명 (등록된 직원명과 일치해야 함) |
| E | 출근 시간 |
| F | 퇴근 시간 |

다른 열은 현재 근태 파서에서 사용하지 않습니다. 이름이 일치하지 않거나 날짜 등이 누락된 행은 제외될 수 있으니, 정산 전에 직원별 근태와 가져온 행 수를 확인해 주세요.

### 파일별 용도

- **엑셀 (`.xlsx`)**: 대시보드, 급여대장, 직원별 상세명세, 근태기록과 선택적 전월 비교 시트를 포함하는 다중 시트 파일
- **PDF / ZIP**: 개인별 임금명세서 또는 여러 직원의 명세서 묶음
- **CSV (`.csv`)**: 대시보드에서 내보내는 급여 정산 감사 자료
- **JSON (`.json`)**: 직원 정보 백업, 전체 백업, 근태와 계산 설정을 포함한 급여대장 결과 패키지

## 개인정보와 데이터 관리

**주의:** 직원 데이터에는 주민등록번호, 계좌번호, 급여액, 출퇴근 시간처럼 민감한 정보가 들어갈 수 있습니다.

- 데이터는 브라우저 `localStorage`에 보관되며, **암호화된 서버 저장소가 아닙니다.** 같은 기기나 브라우저 프로필에 접근 가능한 사람에게 노출될 위험이 있습니다.
- JSON/엑셀/PDF로 내보낸 파일에도 개인정보가 포함될 수 있습니다. 실제 직원 자료를 공개 저장소에 올리지 마세요.
- 브라우저 데이터를 지우거나 기기를 변경하면 기록이 사라질 수 있습니다. 본인이 관리하는 안전한 장소에 백업을 보관하세요.
- 서버 기반 사용자 계정, 권한 분리, 다중 사용자 동기화 기능은 현재 없습니다.
- 실제 임금 지급 전에는 근로계약·수당 지급 요건·반올림·소득세·4대보험 적용 요율과 계산 결과를 별도로 확인해야 합니다.

공개 데모를 보여줄 때는 **가상의 직원 정보와 임의로 만든 출퇴근 자료**만 사용해 주세요.

## 코드 구조

```text
src/
├── App.tsx                  # 화면 이동과 로컬 저장
├── views/
│   ├── Main.tsx             # 대시보드, 과거 이력, 감사·백업
│   ├── EmployeeManagement.tsx
│   └── PayrollCreation.tsx  # 근태 업로드·검토·정산
├── components/
│   └── WageStatementSheet.tsx
├── lib/
│   ├── storage.ts           # 브라우저 저장
│   ├── dataValidation.ts    # JSON 백업 검사
│   ├── excelExport.ts       # 서식 있는 Excel 생성
│   └── pdfExport.ts         # PDF/ZIP 내보내기
└── types.ts                 # 데이터 구조
```

**주요 기술:** React 19, TypeScript, Vite 6, Tailwind CSS, `xlsx-js-style`, `jspdf`, `html2canvas-pro`, `jszip`, `date-fns`.

## 프로젝트 범위

이 저장소는 로컬 환경에서 급여 정산 흐름을 정리하는 프로젝트입니다. 실제 개인정보를 안전하게 처리하는 상용 인사급여 시스템, 법정 임금 계산 검증 서비스, 세무 기관 연동 제품으로 소개하지 않습니다.
